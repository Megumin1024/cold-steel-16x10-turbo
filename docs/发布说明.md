## 闪之轨迹1：16:10 画面适配与加速按键切换 v1.0.0

**仅适用于 README 指定 SHA-256 的《闪之轨迹1》PC v1.6 ed8.exe。** 标题黑条与预录视频保持原样，不支持其他版本的兼容性承诺。

### 下载与使用

普通用户下载 `ColdSteel-16x10-Turbo-v1.0.0-Windows-x64.zip`，解压后运行其中的 EXE，无需安装 Python。也可单独下载同名 EXE；第三方许可见仓库 `licenses/`。

先退出游戏，选择包含 ed8.exe 的目录和屏幕支持的 16:10 分辨率，点击“安装并备份”。重启游戏后，沿用原加速键：按一下开启，松开保持，再按一下关闭；沿用原场景与战斗倍率。
