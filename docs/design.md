- 仅支持 README 列出的 ed8.exe 和原始 HBAO 库 SHA-256。
- 发布 deckscreen.dll 的 SHA-256 为 a1cf73a231254d330f9e7abbe9db36ccb09c0c53450225e1845409cbfc9d4892；禁止用后来的图标/HUD 改版替换。
- 加速模块 SHA-256 为 60e631c79432beac65cba03ba0f0f2987a635ae68a84568db50bc920a8a2147c。
- 不分发 ed8.exe、原始 HBAO 库、存档、私人配置、日志或本机路径。
- 不修改游戏程序、存档、键位或加速倍率；仅启用原生加速并设置用户选择的 16:10 分辨率。
- 标题与预录视频保持既有行为。

## 安装和恢复

先生成完整变更计划、验证载荷和目标版本，再将原文件与恢复清单保存到独立备份目录。安装记录先置为正在安装，成功后置为已安装。每次写入前再次验证目标内容未变化；异常时从记录执行恢复。

卸载先检查全部备份和目标文件。DLL 或受管理配置项被修改时停止；XML/INI 只恢复被本次修改的字段。已有 ATMT 加载器的 Mods 列表只移除本次追加的名字，保留后来新增的无关模块。首次创建的配置发生改动时停止，防止误删后来使用它的模块。原备份与卸载前快照均保留。

不自动提权、不改系统持久设置、不启动或自动操作游戏。图形界面使用标准 tkinter，安装器由 PyInstaller 打包，模块维持已验证二进制。
